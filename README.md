# cosplay二次元摄影相关技能备份仓库

用户技能备份仓库：围绕 **二次元 cosplay 与线下漫展** 的一站式内容生产工具集——找活动、收图、剪视频，全部自动化。

## 包含技能

| 技能 | 说明 | 当前版本 |
|---|---|---|
| acg-event-scout | 二次元线下活动侦察：按城市/时间范围搜索漫展、only展、一日店长、签售、巡游巴士、游戏联名等并提取 coser 嘉宾 | v4 |
| 4khd-scraper | 4KHD 网站 coser 图集搜索与批量下载，按图集名称自动建文件夹、去重、断点续传 | — |
| coser-image-collector | 全网搜集指定 coser 高清图包并下载（微博/B站动态/元气小站等多平台） | — |

## 同步机制

- 每次技能优化完成后自动 `git add + commit + push` 到本仓库
- 技能版本号命名规则：每次优化 +1（v1 → v2 → v3 …），并在对应 SKILL.md 维护版本记录区
