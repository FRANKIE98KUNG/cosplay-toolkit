# ACG Event Scout（二次元活动侦察）

## 版本记录
- **v4（当前）**：主题店官方账号主页直查（宅喵屋等，官方账号作品/笔记列表=完整排期库）；新增"节日店长"身份标签（中秋店长等）；补充宅喵屋门店地址
- **v3**：广州本地老字号餐饮联名（陶陶居/点都德/广州酒家等）；IP×品牌联名必须深挖一日店长coser、禁止默认"无coser驻场"；本地活动聚合号信源（如"广州城市活动Pro"）
- **v2**：游戏官方巡游巴士/痛巴/校园行活动形态；广州本土厂商IP（鸣潮/战双帕弥什/重返未来1999/如鸢）专项搜索
- **v1**：初始版本

多平台并行搜索指定城市、指定时间范围内的线下二次元活动，输出结构化活动清单（含时间、地点、门票、嘉宾阵容）。

## 输入参数

从用户需求中提取以下参数，缺失时用默认值或主动询问：

| 参数 | 默认值 | 说明 |
|---|---|---|
| 城市 | 广州 | 支持任意城市，搜索关键词中替换 |
| 时间范围 | 未来一个月 | 如"9月""10月""本周末""未来两个月"。**重要**："未来一个月"=从当前日期起算30天，包含**本月剩余天数+下月**，搜索时必须同时覆盖本月和下月（如8月27日搜索需同时搜"8月"和"9月"），禁止只搜下个月导致漏掉本月剩余活动 |
| 活动类型 | 全部 | 可限定：漫展/only展/一日店长/音乐会/主题餐厅/摄影展/游戏官方活动 |
| 是否需要嘉宾 | 是 | 用户明确说"只要活动不要嘉宾"时跳过嘉宾深挖 |

## 核心痛点与铁律

1. **B站会员购详情页无法靠关键词搜索命中**：`show.bilibili.com/platform/detail.html?id=xxx` 是单页应用（SPA），活动正文靠 JS 动态渲染，百度/谷歌/微博/小红书/微信等搜索引擎都索引不到正文，只会收录标题壳。用"活动名 + 关键词"全站搜索经常一无所获，这**不代表活动不存在**。

2. **正确路径是解析短链接**：B站活动分享链接形如 `https://b23.tv/xxxxxx`。用 `curl -sI` 解析 302 跳转即可拿到真实活动 ID，再用 web.fetch 抓详情页。详见下方"第四步：B站会员购详情页精准抓取"。

3. **拿到 b23.tv 短链接后必做**：用户提供活动链接，或搜索结果中出现 b23.tv 短链时，不要再用关键词搜，直接解析跳转拿到 id，再抓详情页一次性提取全部字段。

## 搜索流程（按顺序执行，可并行）

### 第一步：通用搜索快速拉取（general_search，3条并行）

用 `general_search` 同时搜索以下4组关键词，快速覆盖三平台公开内容：

1. `{城市} {时间范围} 漫展 coser嘉宾`
2. `{城市} {时间范围} 二次元活动 only展 一日店长 签售`
3. `{城市} {时间范围} 漫展 嘉宾 时间 地点`
4. `{城市} {时间范围} 游戏IP 联名 快闪 一日店长 海底捞 奶茶`（覆盖游戏×品牌联名活动，如金铲铲×海底捞、原神×喜茶、鸣潮×陶陶居等；**联名活动必须再深挖一日店长coser环节，见"IP×品牌联名"铁律**）
5. `{城市} {时间范围} 游戏 巡游巴士 痛巴 校园行 高校巡游 快闪店 周年庆`（覆盖游戏官方城市巡游/线下活动，如鸣潮「启程！巡游巴士」广州站9.13起、金铲铲五周年生日派对等；这类活动关键词不含"漫展"，官宣首发小红书/微博官方账号，通用搜索索引滞后）

**要点**：
- 时间范围用自然语言，如"9月""10月""本周末"；**"未来一个月"必须同时搜本月和下月**（如8月底搜索需同时搜"8月"和"9月"）
- 从搜索结果中提取抖音(iesdouyin.com)、B站(bilibili.com)、小红书、微博、喵特网(nyato.com)、豆瓣等来源
- 记录每个活动的名称、日期、地点、嘉宾，标注来源URL
- **特别留意 b23.tv 短链接**，发现后立即走第四步详情页精准抓取流程
- **游戏官方账号发布的联名活动**（金铲铲、原神、王者、光与夜之恋等）常含一日店长/快闪，关键词不含"漫展"，第4组搜索专门覆盖

### 第二步：专业漫展平台深挖（web.fetch）

用 `web.fetch` 抓取以下平台的活动列表页，snippet query 用 `{城市} {时间范围} 漫展 活动 时间 地点 嘉宾`：

**漫展聚合站**：
1. **喵特网**：`https://www.nyato.com/manzhan/` — 最全面的漫展信息平台，按城市和月份筛选（广州城市码440100）
2. **爱漫展**：`https://www.aimanzhan.com/` — 漫展预告聚合
3. **次元黄页**：`https://yunmanzhan.com/`
4. **零距离会展排期**：`http://090expo.com/news/` — 月度"广东动漫展排期表"

**票务平台**：
5. **B站会员购**：`https://mall.bilibili.com/neul-next/ticket/home.html` — 漫展票务和演出信息（首页是JS渲染，web.fetch能拿到部分热门活动卡片）
6. **大麦网**：`https://search.damai.cn/search.htm?keyword={城市}+漫展` — 大型漫展/Live 票务
7. **猫眼演出**：`https://show.maoyan.com/` — 演出票务

**同人/谷子专属平台**：
8. **CPP无差别同人站**：`https://www.allcpp.cn/` — only同人展参展信息和售票主阵地
9. **千岛**：谷子/同人本预售平台，only展周边信息

**要点**：
- 喵特网注意区分"已过期(expired)"和"未过期"活动，只取目标时间范围内的
- B站会员购按城市筛选，注意票务状态（在售/即将开始/已结束）
- 记录活动的精确日期、地点、票价、嘉宾标签
- only展几乎都在 B站会员购/CPP/千岛/闲鱼 售票，通用搜索容易漏

### 第三步：社媒平台站内搜索（浏览器自动化，按需登录）

如果通用搜索和专业平台信息不够全面（如嘉宾阵容缺失、小众only展未收录），进入社媒平台站内搜索：

#### 小红书（重点：一日店长/签售/小众only/取消延期信息的主阵地）

**为什么必须搜小红书**：一日店长活动、**签售活动**（coser到店签名售周边，与一日店长是不同类型）、小众only展（宾权/魂教猎/音乐剧only等）、活动取消/延期公告、coser个人行程、**二次元主题店官方活动**（宅喵屋等），这些信息在通用搜索和漫展聚合站几乎收录不到，90%首发在小红书。实际操作中，小红书搜索能补充约 30-40% 的活动数量。**签售活动标题常写"签售活动"而非"一日店长"，必须单独搜"签售"关键词。**

**执行方式**：使用 `computer_use_tool`（plane="bu"）+ `seed_browser_use as bu` 操作浏览器，**不要**用 web.fetch（小红书页面是JS动态渲染，web.fetch拿不到搜索结果）。

**搜索URL模板**：`https://www.xiaohongshu.com/search_result?keyword={URL编码关键词}`

**餐饮/零售品牌联名维度**：海底捞、喜茶、奈雪、茶百道、霸王茶姬、瑞幸、库迪、麦当劳、肯德基、必胜客、名创优品、泡泡玛特、animate、潮玩星球——这些品牌常与游戏IP联名推出一日店长/快闪店。**广州本地老字号/本地餐饮品牌（必搜）**：陶陶居、点都德、广州酒家、莲香楼、泮溪酒家、荣华楼、皇上皇——本地老字号与热门游戏IP联名越来越多（如鸣潮×陶陶居「月满玄方其乐陶陶」），**联名常含一日店长coser专场**（如9.20一日店长=Momoko葵葵、零零好困zZ），通用搜索收录不到，必须用"IP名+老字号品牌名+联名/一日店长"单独搜

**网页版限制与应对（重要）**：
- 小红书网页版**可以搜索并读取搜索结果列表**（笔记标题、作者、发布时间、赞数、摘要文本），这是主要信息来源
- 小红书网页版**无法打开笔记详情**（会提示"当前笔记暂时无法浏览，请打开小红书App扫码查看"或"安全限制 访问链接异常"）
- **不要尝试**直接导航到 `/explore/{note_id}` 或 `/search_result/{note_id}` 读取详情，一定会被拦截
- 正确做法：从搜索结果列表的**标题和摘要文本**中提取信息（`bu.get_page_text()` 返回的文本已包含笔记标题和部分摘要）
- 如需笔记全文/图片中的详细信息，告知用户"该笔记详情需在小红书App中查看"，或请用户在App中扫码后继续

**操作步骤**：
1. `bu.navigate("https://www.xiaohongshu.com/search_result?keyword={编码关键词}")`
2. `bu.wait_for_load(timeout=15)` + `time.sleep(3)` 等待JS渲染
3. `bu.get_page_text()` 读取页面文本，提取笔记列表（标题、作者、时间、赞数、摘要）
4. 如需更多结果，`bu.scroll()` 向下滚动加载更多，再读取
5. 换关键词重复以上步骤

**登录处理**：
- 小红书搜索需要登录态。先导航到搜索页，用 `bu.get_page_text()` 确认是否有搜索结果
- 如果页面跳转到登录页或弹出登录二维码，调用 `interaction.request_action(type="browserControl")`，告知用户"小红书需要登录才能搜索，请扫码登录，完成后交回控制权"
- 用户登录后，重新 `bu.snapshot()` 确认登录态，然后继续搜索
- **不要**反复尝试关闭登录弹窗，也不要用其他平台替代小红书搜索

**从搜索结果提取信息的要点**：
- 笔记标题中常含完整活动名+日期+地点（如"9.6广州宾权only2.0应援场无料list"、"广州宅喵屋签售活动·九月新情报"）
- 作者名可判断信息来源可信度（**官方账号 > 活动主办方 > 个人博主**）；宅喵屋、萌果酱等店铺官方账号发布的活动信息最权威，优先提取
- 赞数高的笔记通常信息更全面，但**最新发布的笔记（几小时前）可能含刚官宣的签售/一日店长活动**，通用搜索尚未索引，必须靠小红书站内搜获取
- 签售活动标题常写"签售活动""签售嘉宾""签售情报"，与"一日店长"是不同类型，不要混淆
- "大家都在搜"区域的相关关键词可作为补充搜索线索
- 搜索结果按"最新"排序可优先获取刚官宣的活动，按"最热"排序可获取高赞汇总笔记

**本地活动聚合号（重要信源）**：小红书上的城市活动聚合账号（如"广州城市活动Pro"）会跨月发布本地二次元活动总表（含only展/联名/快闪及待官宣档期），对单个联名活动的细节（一日店长coser名单、门店、时段）往往比官方公告更早更全。搜索时定向搜"城市名+活动Pro/城市活动/活动情报/活动总表"，找到聚合号后浏览其近期笔记，可一次补全多个易漏活动；聚合号发布的联名活动必须同步深挖一日店长coser（见"IP×品牌联名"铁律）。

- 关键词：`{城市} {本月} 漫展`、`{城市} {下月} 漫展`、`{城市} 一日店长`、`{城市} 签售`、`{知名店铺名} 签售/一日店长`、`{coser名} 行程`、`{热门游戏IP} 联名 快闪 一日店长`
- 微博实时搜索能搜到最新官宣和返图
- coser本人会公布当月线下行程（如"8.23 广州宅喵屋"、"8.28 广州海底捞"、"9.13 宅喵屋签售"）
- 一日店长和签售活动多由主题店（萌果酱、谷子快跑、次元波板糖、宅喵屋等）和**餐饮品牌联名门店**（海底捞、奶茶店等）官宣
- 游戏官方微博常发布联名活动公告，关注金铲铲之战、原神、光与夜之恋等IP的官方账号
- 签售活动与一日店长是不同类型，必须单独搜"签售"关键词

- 很多活动官宣首发微信公众号，用 general_search 搜 `{城市} {活动名} 公众号` 或 `{城市} 漫展 官宣`
- 主题店/同人展主办方通常有公众号发布排期

### 第四步：B站会员购详情页精准抓取（b23.tv 短链解析）

当从任何渠道（用户提供、搜索结果、小红书笔记、微博官宣）发现 B站活动短链接 `https://b23.tv/xxxxxx` 时，执行以下流程获取完整活动详情：

**步骤1：解析短链接获取活动ID**
```bash
curl -sI "https://b23.tv/<code>" -H "User-Agent: Mozilla/5.0" | grep -i location
```
从 `Location:` 头中提取 `id=<数字>`（跳转目标形如 `https://mall.bilibili.com/neul-next/ticket-renovation/detail.html?id=1005005...`）。

**步骤2：抓取详情页**
用 `web.fetch` 抓 `https://show.bilibili.com/platform/detail.html?id=<id>`，提取以下字段：
- 活动完整名称、副标题/主题
- 时间（起止日期时刻）
- 场馆/地址（含区）
- 票价（各票种+开售时间）
- 参展嘉宾（coser/声优/唱见全名单）——从"参展嘉宾"和"签售票"档位两个地方合并去重
- 活动介绍、入场规则、主办方
- 购票平台

**已踩过的坑（不要重试）**：
1. `show.bilibili.com/platform/search?keyword=` 返回 404
2. `show.bilibili.com/api/ticket/project/search` / `list` 接口有风控和复杂参数校验（返回"被降级过滤"或参数错误）
3. `api.bilibili.com/x/web-interface/search/type?search_type=show` 返回 code=-1200 被降级过滤
4. 首页 `show.bilibili.com/platform/home.html` 是 JS 渲染，curl 拿不到活动数据，但 web.fetch 能拿到部分热门活动卡片

**结论**：拿到短链接 → `curl -sI` 解析 id → web.fetch 详情页，是唯一可靠路径。不要试图用关键词搜索 API 命中 SPA 详情页。

### 第五步：已知活动嘉宾深挖（按需）

对于前四步找到的重要活动，如果嘉宾信息缺失，用 `general_search` 单独搜：

- `{城市} {活动全名} 嘉宾 coser`
- `{活动全名} 签售 嘉宾阵容`
- `{活动全名} 官宣`
- `{coser名} 行程`（定向挖coser当月线下行程）

一日店长活动：微博搜"<城市> 一日店长"或"<coser名> 一日店长"，线索常在小红书笔记标题+微博转发里。
签售活动：小红书/微博搜"<城市> 签售"或"<店铺名> 签售"或"<coser名> 签售"，签售活动标题常写"签售活动""签售嘉宾"，与一日店长不同，必须单独搜。

### 嘉宾信息完善铁律（每次必须执行）

收集活动信息时，嘉宾/演出阵容必须**尽可能全面列举**，禁止只写"有嘉宾"敷衍：

1. **多来源核验**：嘉宾名单优先取自 B站会员购详情页（"参展嘉宾"字段与"签售票"档位合并去重）、活动官方微博/公众号宣发图、主办方海报；同一活动多平台出现时合并取最全版本
2. **逐个活动确认**：每个活动都必须在嘉宾列给出具体名单；确实无法确认的标注"嘉宾待官宣"，并尽可能附参考线索（如该活动往届场次嘉宾、同场馆/同主办方近期场次的嘉宾）
3. **特殊活动类型必挖**：
   - **一日店长/签售**：必须确认具体 coser 名单、对应门店/日期/时段（例："海底捞×金铲铲广州 8.28 一日店长=爪琊（珠影星光城店），9.4-6 五城轮换"），参与门槛（消费/预约/抖音团购）一并注明
   - **演唱会/Live**：歌手、配音演员、乐队成员全名单（例：剑网3庆典=龚琳娜+20位国风歌手+14位配音演员）
   - **音乐会**：演奏乐手名单 + 曲目单（标注涵盖哪些 IP 作品）
   - **漫展**：参展 coser 嘉宾名单；自由行/舞台嘉宾另列
4. **标注来源**：区分官宣来源（B站详情页/官方微博/公众号）与非官宣（网传），网传标"待确认"
5. **时间校验**：搜索极易混入往届同月活动数据（如去年中秋档），只采用本场次官宣信息，过期场次的嘉宾一律弃用

### xlsx 表格输出（默认交付物，与对话清单同步）

除对话内结构化清单外，**默认同步生成一份 xlsx 存档表**（用户偏好表格交付，便于存档/查阅/汇报），含两个 sheet：

**Sheet1「活动总表」**：列 = 日期｜星期｜活动名称｜类型｜地点｜门票｜嘉宾/看点｜来源/备注
- 按时间排序；跨月快闪/主题店归入"跨月"区；超出时间范围的列入"供参考"区
- 格式：表头深蓝底白字加粗、冻结首行、全部单元格加细边框、长文本列（活动名/地点/嘉宾/备注）自动换行

## 去重与校验规则

1. **同名活动去重**：同一活动在多个平台出现时合并信息，取最完整的版本
2. **时间校验**：活动日期必须落在用户指定的时间范围内，超出范围的列入"供参考"区
3. **嘉宾校验**：嘉宾名单优先取主办方官宣来源（B站详情页/官方微博/公众号），非官宣来源标注"网传/待确认"
4. **时效性**：标注信息获取时间，提醒用户活动信息可能更新，建议关注主办方账号
5. **城市校验**：确认活动地点确实在目标城市，避免把周边城市（如佛山、东莞）误算入
6. **嘉宾名单合并去重**：从详情页"参展嘉宾"和"签售票"档位两个地方提取后合并去重

## 注意事项

- **时间范围铁律**："未来一个月"=从当前日期起30天，必须同时搜索**本月剩余天数+下月**，禁止只搜下个月。如8月27日搜索必须同时搜"8月"和"9月"，否则会漏掉8月28-31日的活动（如金铲铲×海底捞8.28一日店长）
- 小红书是一日店长、小众only展、活动取消/延期信息的主阵地，必须搜；用 computer_use_tool+seed_browser_use 操作浏览器，不要用 web.fetch（JS渲染拿不到结果）
- 小红书网页版只能读取搜索结果列表（标题/作者/摘要），无法打开笔记详情（需App扫码）；不要尝试直接导航到 /explore/ 或 /search_result/{note_id}，一定会被拦截
- 小红书搜索需登录，遇到登录弹窗时调用 interaction.request_action 请求用户扫码，不要反复尝试关闭弹窗
- 出行前额外搜"{城市} 漫展 取消/延期"，小红书上的取消公告往往比票务平台更新更快
- **游戏IP×品牌联名活动极易遗漏**：金铲铲×海底捞、原神×喜茶、鸣潮×陶陶居、光与夜之恋×主题餐厅等，关键词不含"漫展"，通用搜索和漫展聚合站完全收录不到。必须用"IP名+品牌名+联名/快闪/一日店长"单独搜索，重点关注游戏官方小红书/微博账号发布的联名公告
- **IP×品牌联名必须深挖coser/一日店长环节，禁止默认"无coser驻场"**：本地老字号（陶陶居、点都德、广州酒家等）与游戏IP联名常含独立于打卡期的"一日店长Coser"专场。确认联名活动时，必须用"IP名+品牌名+一日店长/coser/签售/驻场"单独搜；只有多方信源确认确实无coser环节，才可标注"无coser驻场"。例：鸣潮×陶陶居「月满玄方其乐陶陶」=主题门店9.19-9.27（陶陶居酒家第十甫路总店）+线下大屏9.19-9.24（北京路LED）+一日店长9.20（Momoko葵葵、零零好困zZ），打卡发帖领联动明信片
- 一日店长不仅在二次元主题店（宅喵屋等），也大量出现在**餐饮品牌联名门店**（海底捞、奶茶店、咖啡店），搜索时必须覆盖品牌联名维度
- **签售活动与一日店长是不同类型，必须单独搜"签售"**：签售是coser到店签名售周边，标题常写"签售活动""签售嘉宾"而非"一日店长"。如宅喵屋9.13爆炸小可乐+蜜汁猫裘签售，搜"一日店长"搜不到，必须搜"签售"或店铺名+"签售"
- **必须针对知名二次元主题店单独搜索**：宅喵屋、萌果酱、谷子快跑、次元波板糖、BM次元基地等店铺几乎每周都有签售/一日店长，官方账号发布的信息最权威。用"店铺名+月份"、"店铺名+签售"、"店铺名+一日店长"单独搜索，比泛化的"广州 一日店长"精准得多。**且必须直查其抖音/小红书官方账号主页**：作品/笔记列表（置顶+近期）是完整排期库，关键词搜索只能命中零散几条（如宅喵屋9月5场一日店长/签售全部只在官方账号主页可见）
- **新发布笔记（几小时前）只能靠小红书站内搜获取**：通用搜索对新发布内容有索引延迟，宅喵屋等店铺官宣的签售活动可能发布仅几小时，必须在小红书站内按"最新"排序搜索才能获取
- 喵特网部分活动标注"expired(已过期)"，注意区分年份，不要把去年的活动当成今年的
- 小众only展（如覆面系、国乙、术力口）在通用平台收录少，必须在抖音/小红书站内搜才能找到，同时查CPP/千岛/闲鱼
- 一日店长活动通常由店铺或coser个人发布，信息分散，需要搜"一日店长+城市"关键词，同时搜热门coser名+"行程/一日店长"
- 嘉宾阵容常分批官宣，搜索时如果只找到部分嘉宾，标注"更多嘉宾待官宣"
- **游戏官方线下活动（周年庆/生日派对/快闪/巡游巴士）极易遗漏**：这类活动由腾讯/网易/米哈游/库洛等游戏官方举办，通常持续多天、免费、有人气coser驻场，但宣传关键词不含"漫展"，传统搜索容易漏掉。必须额外搜索"游戏 线下活动/周年庆/生日派对/快闪/巡游巴士/痛巴/校园行"等关键词，重点关注原神、崩坏、星穹铁道、绝区零、英雄联盟、王者荣耀、金铲铲、光与夜之恋、恋与制作人、第五人格、阴阳师、鸣潮、战双帕弥什、重返未来1999等热门IP的官方账号。**尤其广州本土厂商（库洛游戏-鸣潮/战双帕弥什、深蓝互动-重返未来1999、灵犀互娱-如鸢）**：其线下活动基本都落地广州、官宣首发小红书/微博官方账号，必须用"IP名+巡游/巴士/校园行/快闪/线下活动"单独搜
- B站会员购详情页是SPA，搜索引擎索引不到正文，搜到标题壳不代表活动不存在；拿到b23.tv短链后必须走解析流程
- 不要尝试调用B站会员购搜索API（已被风控降级），唯一可靠路径是短链解析+详情页web.fetch
